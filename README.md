# Page OCR для Doc88

Расширение для Chrome и Edge сохраняет открытый документ Doc88 как PDF с поиском и копированием текста. Распознавание русского и английского выполняется в браузере. Обе модели входят в комплект.

## Установка

1. Распакуй ZIP в постоянную папку.
2. Открой `chrome://extensions` или `edge://extensions` и включи «Режим разработчика».
3. Нажми «Загрузить распакованное расширение» и выбери папку с файлом `manifest.json`. Закрепи значок Page OCR на панели браузера.

## Экспорт

1. Открой документ на Doc88. Если сайт требует вход или подтверждение чтения, пройди его в браузере.
2. Нажми значок Page OCR, проверь название и число страниц и выбери «Собрать PDF с OCR».
3. Оставь вкладку документа открытой до окончания загрузки листов. Когда начнётся распознавание, можно закрыть документ. Оставь открытой вкладку «Ход выполнения».
4. Готовый PDF появится в загрузках браузера под названием документа. Кнопка «Показать в папке» откроет его расположение.

Page OCR сверяет обозначение из заголовка и первой страницы с каталогами Росстандарта, ISO и DIN Media. Сверка поддерживает ГОСТ, ПНСТ, ISO, EN и обозначения DIN, BS и NF, опубликованные в каталоге DIN Media. Для ISO расширение сначала проверяет локальные записи ISO 668, а для других стандартов сверяет открытый набор данных и сайт ISO. Название из каталога используется при точном совпадении обозначения и издания. После экспорта показывается источник названия.

Расширение берёт полное изображение каждого листа из просмотрщика. В PDF сохраняются исходные пропорции, белые поля и номера страниц. Границы листа определяются по его изображению, независимо от масштаба и прокрутки окна. Если браузер ограничивает чтение изображения, расширение покажет причину.

Расширение сначала пробует повысить разрешение в просмотрщике Doc88. Если разрешение листа сильно ниже 3840 пикселей по длинной стороне, расширение усиливает контуры, увеличивает растр и сжимает его в JPEG для записи в PDF. Масштаб ограничен четырьмя кратами, а площадь изображения — 12 мегапикселями. Для распознавания используется исходное изображение листа до JPEG-сжатия. Поиск и копирование текста работают через слой OCR. В итогах отдельно показаны разрешения источника и PDF. Исходный масштаб просмотрщика восстанавливается после загрузки листов.

Если Doc88 запросит подтверждение во время загрузки листов, пройди его на сайте и запусти экспорт снова. На Doc88 поддерживаются документы до 500 страниц.

## Доступы

Для загрузки листов расширение использует доступ к открытой вкладке. Разрешение на загрузки используется для сохранения готового PDF. Страницы и распознанный текст обрабатываются на устройстве. Для проверки заглавия расширение отправляет в каталог только обозначение стандарта. Доступ к Росстандарту, ISO и DIN Media нужен для сверки заглавия.

Сведения о зависимостях и их лицензиях приведены в файле THIRD_PARTY.txt.

Для сверки используется набор [ISO Deliverables Metadata](https://www.iso.org/open-data.html#iso_deliverables_metadata) из [ISO Open Data](https://www.iso.org/open-data.html), доступный по лицензии [ODC Attribution License v1.0](https://opendatacommons.org/licenses/by/1-0/).
